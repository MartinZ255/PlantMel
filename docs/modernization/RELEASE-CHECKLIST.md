# Release-Gates

- [ ] Alle Änderungen auf separatem Branch/PR nachvollziehbar
- [ ] Tests/Lint/Typecheck/Build erfolgreich oder Abweichungen dokumentiert
- [ ] Mobile, Tablet, Desktop und Tastaturbedienung getestet
- [ ] Auth-/Berechtigungs- und Datenintegritätsprüfungen abgeschlossen
- [ ] Staging mit separater Datenbank und nicht-produktiven Zugangsdaten
- [ ] Produktionsbackup erstellt **und Wiederherstellbarkeit überprüft**
- [ ] Migrationsfolgen und Kompatibilität geprüft
- [ ] Deployment- und Rollback-Schritte dokumentiert
- [ ] Explizite Freigabe für genau dieses Deployment erteilt
- [ ] Post-Deploy-Smoke-Test und Monitoring durchgeführt
